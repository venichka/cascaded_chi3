# Archive

Superseded material, kept for the record. Nothing here is used by the current notes, code or paper.

- `Cascaded_chi3_metasurface_note.md`: Markdown rendering of the main note as of April 2026. The current version is `notes/Cascaded_chi3_metasurface_note.tex`.
- `cascaded_chi3_simulation.py`: the first single-file TCMT simulation, replaced by the modular scripts in `cascaded_chi3/`.
- `alternative_chi3/`: early application studies (phase and bandwidth, Q scaling, bistability, FWM, saturable absorber, AM modulator, sensor). They import `cascaded_chi3_simulation.py` from an absolute path and use the coupling prefactors of the April note, so they do not run as they are. The maintained versions are the corresponding `fig_*.py` scripts in `cascaded_chi3/`.
