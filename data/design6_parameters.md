**Source deliverables** (received 2026-07-13, in `data/`): `design6.mat` (COMSOL spectra) and
`design6.pptx` ("Design 6 — by Dee & Yajun", updated 2026-07-06). This file is the single
authoritative, cross-checked parameter set for the SH-only cascaded-χ³ simulations of
`Cascaded_chi3_SH_only_note.tex`. Every number is reproduced/verified by the promoted code
`cascaded_chi3/design6_params.py` (extraction + verification report) and the observable suite
`cascaded_chi3/design6_effects.py` (figures → `cascaded_chi3/figures/design6/`); the
full-precision frequency sweep is in the companion `data/design6_spectrum.csv` (14 cols, 61
rows), regenerated by `design6_params.write_spectrum_csv()`.

> Run `conda run -n ml_base python design6_params.py` (extraction) and
> `conda run -n ml_base python design6_effects.py` (observables) to reproduce everything.

> **Design 6 is a NEW single design, not one of samples 1–4.** It differs from the earlier
> LiNbO₃ set in four load-bearing ways — read §1 before reusing any old script assumption.

## 0. What changed vs samples 1–4 (read this first)

| Aspect | Samples 1–4 | **Design 6** |
|---|---|---|
| Material stack | pure LiNbO₃ pillars | **TiO₂ pillars on a LiNbO₃ slab** (hybrid; only LN is nonlinear) |
| qBIC asymmetry | pillar **height** (H1≠H2) | pillar **etch-angle** α = 0° vs 90° (two elliptical holes in TiO₂) |
| Optical axis / active field | E_z (out-of-plane), d₃₃, nₑ | **E_x (in-plane)**, optical axis ∥ x, `n_x = nₑ`, only d₃₃/E_x |
| Overlap normalisation | `overlap`/**area** (2-D, m²) | `overlap`/**volume** (3-D, m³) — see §5 |
| Pump wavelength | λ₁ ≈ 0.97–1.06 µm (green SH) | **λ₁ ≈ 1.757 µm**, SH λ₂ ≈ 878 nm (near-IR) |
| Q₂ / overlap trade | Q₂ ≈ 3400–5600, overlap ≈ 0.10–0.22 | **Q₂ ≈ 924, overlap ≈ 0.41–0.44** (low-Q, high-overlap) |
| `.mat` normaliser field | `area` (m²) | `volume` (m³) |

The **area → volume** switch is the most important change: the designer now supplies a full
**3-D volume-normalised** SHG overlap, which is dimensionally the *correct* match to the model's
3-D mode overlap M̃ (`eq:Mtilde-def`) and is on firmer footing than the old 2-D area overlap. See §5.

## 3. Conventions and unit conversions

- **Frequencies.** Table f₀ is the **SH** centre. ω₁ = π·f₀, ω₂ = 2π·f₀ = 2ω₁. λ[µm] = 299.792/f[THz].
- **Linewidth.** `γ[THz] = f₀/Q₂` = FWHM in ordinary frequency. Model `γ₂ = ω₂/Q₂ = 2π·γ[THz]`
  (SH energy decay, rad/s). Usable Kerr bandwidth `Δf = γ₂/2π = γ[THz] = 369 GHz`.
- **Tensor axis (changed).** Field ∥ **x** = LN optical axis ⇒ active component `χ⁽²⁾_xxx = 2 d₃₃`,
  relevant index is the **extraordinary** `nₑ`. So `n₁ = nₑ(λ₁)`, `n₂ = nₑ(λ₂)` (same physics as the
  old z-convention, just re-oriented in-plane).
- **Boyd degeneracies** (SHG 1, DFG 2, SPM 3) are baked into the boxed χ³_casc; nothing per-design.

## 4. Geometry / volume cross-check (the structural verification)

The stated `volume` pins the cell geometry exactly:

```
V_LN(geom) = 2 · p² · H_LN = 2 · (219 nm)² · 150 nm = 1.43883×10⁻²⁰ m³
V_LN(.mat) =                                          1.43883×10⁻²⁰ m³   (ratio 1.00000)
```

⇒ the unit cell is a **2p × p supercell** (the two α = 0°/90° pillars) over a **solid, unpatterned
LiNbO₃ slab** of thickness H_LN (holes are etched only in the TiO₂ top layer — consistent with the
pptx cross-section image). The LN is a full slab, so V_LN = A_cell·H_LN with A_cell = 2p². This is a
strong internal-consistency check that our reading of the geometry is correct.

## 5. The overlap → η_geom mapping (now 3-D, the crux)

**New definition (volume-normalised).** The stored `overlap` has volume units (m³); the
dimensionless SHG coherence factor is

```
overlap_dimensionless(f) = |overlap_complex(f)| / V_LN            ∈ [0, 1]
```

reproducing the designer's annotated `overlap(±2γ₂)` (see §8). Physically this is the normalised
3-D SHG mode overlap — exactly the model's `M̃ = ∫_LN χ⁽²⁾_xxx f*_{2,x} ê ê dV` (`eq:Mtilde-def`)
divided by its incoherent maximum. Because χ³_casc ∝ |M̃|² (`eq:chi3-1R-explicit`):

```
η_geom^(1R)(Δω) = ( |overlap_complex(f)| / V_LN )² · C_bridge ,   f = f₀ + Δω/(2π)
```

Two powers (SHG up-conversion × DFG back-conversion, equal by Kleinman). This is the **same
functional form** as the samples-1–4 mapping, with **V_LN replacing area** in the denominator.

**Why this is better than before.** The old 2-D area-normalised overlap forced `C_bridge` to absorb
a 2-D→3-D dimensional mismatch. The volume-normalised overlap is already the 3-D object M̃, so
`C_bridge` now only carries the O(1) difference between the designer's field-norm convention and the
model's Brillouin/ζ₁ normalisation — a genuinely O(1) factor, not a dimensional bridge. `C_bridge = 1`
remains the baseline and is better justified here; still nail it with one absolute SHG-efficiency
point (§7).

**Do not double-count the resonance.** As before, the denominator divides out the resonant SH
*amplitude*, so `overlap` is the **spatial-coherence factor only** (small at Δω=0: a Fano dip to
≈0.036); the Lorentzian/Q₂ build-up is supplied by the model's `1/(Δω+iγ₂/2)`.

## 6. Material parameters at 1.757 µm (supplied by us)

- **Indices** from `ref_idx_LN.m` (Sellmeier, 0.4–5 µm covers both): `n₁ = nₑ(1.757 µm) = 2.132`,
  `n₂ = nₑ(0.878 µm) = 2.168`. Slightly below the old ~2.23–2.26 (longer wavelengths).
- **Effective hybrid index (estimated — resolved for now).** The SH mode lives in a **TiO₂/LiNbO₃
  hybrid**, so the index entering the χ³_casc denominator (n²) is not bare LN nₑ. We estimate it by a
  **volume-fill-weighted effective-medium average** (`design6_params.effective_index`): the LN slab
  (fill 0.379), the TiO₂ layer minus the two air holes (0.517, TiO₂ n≈2.35/2.28 at SH/FM — representative
  amorphous-film value, ±0.1), and the air holes (0.104). Result: **n₂_eff = 2.177, n₁_eff = 2.124** —
  within **<1 %** of bare LN, because TiO₂'s *higher* index and the air holes' *lower* index nearly
  cancel. So the earlier "~±12 %" worst-case flag is superseded: the hybrid barely moves n², and using
  bare LN n₂ instead changes R by <1 %. `n₂_eff` is what the code uses. A COMSOL modal n_eff would refine
  this but is not needed to O(10 %).
- **`|χ⁽²⁾| = 2 d₃₃ = 5×10⁻¹¹ m/V`** (baseline; Miller dispersion to 878 nm SH ~ +10–20%, treated as ±20%).
- **`χ⁽³⁾_native = 2×10⁻²¹ m²/V²`** (baseline). At **1.757 µm** the two-photon energy (2ħω at 878 nm ≈
  1.41 eV) is *further* from the ~3.9 eV gap than at the 1 µm designs (~2.48 eV), so native Kerr is if
  anything **smaller** here — mildly *favourable* for R (opposite sign to the 1 µm concern). Flagged as
  the main material uncertainty (R ∝ 1/χ⁽³⁾_native).

## 9. Derived outputs — the observable suite (`design6_effects.py`, C_bridge = 1)

From `chi3_casc(Δω) = −ω₁|χ⁽²⁾|² η_geom / [6 n₂² (Δω + iγ₂/2)]` with the hybrid `n₂_eff = 2.177`.
All four correctness cross-checks pass (prefactor-free lineshape; analytic-form match to 4×10⁻¹⁶;
units; hand spot-value). Figures in `cascaded_chi3/figures/design6/`.

**At the conservative operating point Δω = +2γ₂:**

| quantity | value |
|---|---|
| η_geom(+2γ₂) / η_geom(−2γ₂) | 0.183 / 0.169 |
| \|χ³_casc(+2γ₂)\| | 3.61×10⁻²¹ m²/V² |
| **R = \|χ³_casc\|/χ³_native** | **1.81** |
| Re χ³(+2γ₂) / Re χ³(−2γ₂) | −3.51×10⁻²¹ / +3.23×10⁻²¹ (sign flip ✅) |
| Im χ³(+2γ₂) | +8.76×10⁻²² (two-photon-like loss) |
| \|χ³\|·Δf | 1.33×10⁻⁹ m² Hz/V² |
| φ_NL single-pass @ 1 / 10 GW cm⁻² | 2.2×10⁻⁶ / 2.2×10⁻⁵ rad (L = 150 nm) |
| \|ΔT/T\| @ 1 GW cm⁻² | 1.1×10⁻⁶ |
| η_FWM / η_SHG @ 1 GW cm⁻² | 5.2×10⁻¹² / 1.3×10⁻⁷ (order-of-mag) |

**Optimal detuning** (data-derived η over the single-pole window \|Δω\|/γ₂ ∈ [1,5]): overlap keeps
rising into the wings, so \|χ³\| peaks at **R = 2.36 at Δω ≈ +4.5γ₂** (η ≈ 0.53), a ×1.31 gain over the
+2γ₂ point. So — unlike samples 1–4 — detuning *is* a modest lever here (broad wing plateau), though ±2γ₂
stays adiabatically clean.

**Pulsed (time-domain TCMT).** Q₂ = 924 gives a **fast** SH lifetime 1/γ₂ = **0.43 ps**, so the
quasi-static χ³ holds with **no penalty even at τ_p = 1 ps**: r_φ = 1.07 / 1.02 / 1.01 at τ_p = 1 / 2 / 3
ps (slight resonant overshoot, not suppression). This is the *opposite* of the high-Q samples (S4: 0.40 at
1 ps). The sign flip survives pulsing. So the ps laser (longest pulse 1–3 ps, confirmed reaching ~1.76 µm)
is comfortably in the quasi-static regime for this design.

**Reading.** Design 6 lands at **R ≈ 1.8** (up to ~2.4 in the wings) — comparable to the old best S3 (1.76)
and approaching S4 (2.49). It gets there by the *opposite* trade: overlap ≈ 0.44 (vs ~0.21) at low Q₂ = 924
(vs 5633). Because R ∝ Q₂·η ∝ Q₂·overlap², the two effects nearly offset (Q₂·η ≈ 169, vs S3 ≈ 172, S4 ≈
248). Still an **overlap-forward, modest** cascade — beats native Kerr but not by a large factor, and
(SH-only) has no CW-Kerr device use; single-pass Kerr phase is µrad-level. The most observable experiments
remain the Re χ³ sign-flip vs detuning, pulsed saturable absorption, SHG efficiency, and broadband FWM.
The absolute R carries the §7/§8 scale uncertainties (C_bridge, native χ³); the *ranking* and Q/η scaling
are far more robust. The low-Q/fast-SH (no pulse penalty) property is a genuine practical advantage over
the high-Q samples for a ps-pulsed measurement.
